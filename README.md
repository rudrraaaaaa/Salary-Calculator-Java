Salary-Calculator-Java

A simple Java application that calculates an employee's salary based on user input.

📌 Description

This is a simple console-based Salary Calculator built using Java. The program accepts employee details and calculates the salary based on user input.

🚀 Features

Accepts employee information
Calculates salary
Displays salary details
Console-based application
🛠️ Technologies Used

Java
Scanner Class
Variables
Arithmetic Operators
User Input
📚 Concepts Practiced

Java Basics
Variables and Data Types
User Input using Scanner
Arithmetic Calculations
Output Formatting

Compile the program
javac Main.java
Run the program
java Main
